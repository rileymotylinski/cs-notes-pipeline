## Controls Hazards
- when we cannot reliably determine the location of the next instruction
- re instruction, looop, conditional jump, etc. (all this stuff is stored on the stack..?)
- need info in the fetch stage that we don't have it yet
- we should just guess?
guess - load next instruction. 


## branch prediction
just start executing, 
if we are right - keep going

if we were wrong, flush incorrect instructions from the pipeline, begin from current branch
- technically this not more wasteful than just waiting


## branch prediction strategies
- given a conditional jump, always jump: 60%
- given a conditional hjump, never jump: 40%
given a conditional jump - if the target is alower address, jump; if a higher

- lots of different branch prediction in modern cpus
- tracks success rate? Updates how often if jumps from there
